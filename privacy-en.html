KLayout Privacy Policy

In one sentence: KLayout is a fully offline layout (GDS/OASIS/CIF/DXF, etc.) viewer and editor. 1. Summary

This privacy policy applies to the HarmonyOS application KLayout (bundle name com.yangy79.klayout, hereinafter "the App").

The App is a purely offline layout viewer and editor. It does not connect to the internet, requests no system permissions, and does not collect, upload, or share any of your personal information or file contents.

2. How We Handle Your Information

2.1 Information We Do Not Collect

The App does not collect, read, or upload any of the following:

  • Personally identifiable information (name, phone number, email, account, device identifiers, etc.)
  • Your location data
  • The contents of any layout file (GDS/OASIS/CIF/DXF, etc.) you open, edit, or save
  • Your contacts, messages, call logs, photo library, microphone, or camera data
  • Usage behaviour, crash logs, or telemetry of any kind

2.2 Information Processed On-Device Only

To provide its core function (layout viewing and editing), the App processes and stores the following data locally on your device. This data never leaves your device:

DataPurposeStorage location
Layout files you open or saveViewing, editing, storageThe location you choose in the system file picker
App settings (window layout, recent files, layer properties .lyp, etc.)Remembering your preferencesApp private directory
Bundled technology libraries, DRC rules, sample macrosProviding default functionalityExtracted to the app private directory on first run

You can permanently delete all of this local data at any time by uninstalling the App.

2.3 Permissions

The App's manifest (module.json) declares no system permissions at all (requestPermissions: []). Specifically:

  • No network permission (ohos.permission.INTERNET) — the App has no networking capability whatsoever and cannot transmit data.
  • No storage permission — opening and saving files is done exclusively through HarmonyOS's system file picker (DocumentViewPicker). The system manages file authorisation; the App only gains access to the specific file you explicitly select.
  • No location, camera, microphone, contacts, calendar, phone, or messaging permissions.

You can verify the permissions the App actually holds under "Settings → Apps → KLayout". Currently this is none.

2.4 Third-Party SDKs and Code

  • The App integrates no third-party SDK (no ad, analytics, push, or map SDK).
  • The App is built on the open-source projects KLayout (GPL-3.0) and Qt 5.12.12 (LGPL-3.0). These are locally running libraries and frameworks with no data-collection or reporting capability. See the Open Source Compliance Statement.

3. Data Security

Because the App does not access the network and collects no data, there is no data transmission or remote storage, and therefore no related risk of data leakage. The security of local data relies on the HarmonyOS application sandbox, together with your device's screen lock and encrypted storage. Please keep your device secure and enable screen locking.

4. Your Rights

Since the App collects, stores, and shares no personal information, there is no need for data access, correction, deletion, consent withdrawal, or account deletion procedures. You have full control over all data associated with the App (which consists solely of local files); uninstalling the App removes all settings and caches from its private directory.

5. Protection of Minors

The App collects no personal information and therefore performs no collection of information concerning minors. The App contains no advertising, paid content, or content unsuitable for minors, and is suitable for all users, including minors. If you are the guardian of a minor and have questions about its use, please contact us using the details below.

6. Changes to This Policy

If this policy changes, we will update this page and revise the "Last updated" date accordingly. If a change materially affects your rights, we will notify you prominently within the App. Please review this page periodically for the latest version.
