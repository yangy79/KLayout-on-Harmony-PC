# reference/ —— 移植期间的原始工作记录

⚠️ **这些是开发过程中的工作笔记与调研报告原件，不是权威文档。**

它们保留了当时的探索轨迹（含走过的弯路、被推翻的结论、以及针对本机构建环境
的临时记录）。阅读时请注意：

- **权威文档**是 [`../PORTING-NOTES.md`](../PORTING-NOTES.md)（问题与解法）、
  [`../BUILD.md`](../BUILD.md)（构建流程）、[`../VERIFICATION.md`](../VERIFICATION.md)（验证结果）。
  三者与本目录内容如有冲突，以它们为准。
- 这些笔记里含**构建机的绝对路径**（如 `/storage/Users/currentUser/dev/...`），
  换机器不适用。
- 笔记中对"方案选择"的讨论属于过程记录，最终采用的方案见上述权威文档。

保留它们的原因：透明地展示移植是怎么做出来的，以及哪些路走不通 ——
对后来做同类移植的人可能比结论本身更有用。
